# Watershed Delineation Using ArcGIS

## Project Summary

This project demonstrates watershed delineation using Digital Elevation Model (DEM) data and hydrological analysis tools in ArcGIS.

## Methodology

1. DEM preprocessing
2. Fill sinks
3. Flow Direction generation
4. Flow Accumulation generation
5. Pour Point identification
6. Watershed delineation
7. Raster to Polygon conversion
8. Watershed area calculation

## Software Used

* ArcGIS
* Spatial Analyst Tools
* Hydrology Tools

## Final Output

A watershed boundary was delineated from DEM data, converted into a polygon, and its area was calculated using GIS geometry tools.
